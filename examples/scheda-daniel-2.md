## WARM UP AND COOL DOWN (valido tutte le sedute)

- mobility generale: 5\10 minuti (spalle, polsi, gomiti, bacino, ecc.)
- preparazione articolare con elastico: 5\10 minuti (intra extra rotatori, ecc.)
- preparazione movimento specifico: 5 minuti (push up, pull up, ecc.)
- verticale libera\muro (condizionamento snc): 10 minuti solo se inserita in scheda
- defaticamento\stretching finale: 5\10 minuti
- (nei 10 minuti iniziali di verticale aggiungi lavori alla parete con switch dei
  piedi per trovare l'equilibrio)

## STRUTTURA PROGRAMMAZIONE

- 5 settimane on + 1 di scarico (totale 6 settimane)
- nella settimana di scarico dimezzare il volume (serie)

> ora ad ogni giorno facciamo 10 minuti di verticale libera + muro obiettivo
> arrivare a stare liberi, 1 giorno la facciamo sulle mani e 1 giorno sulle
> parallele

# Notation legend

Recovered from the source. Formalised in
`skills/program-design/references/notation.md`.

| Symbol | Meaning |
|---|---|
| `2-` | starting set count, **+1 set per week** across the block |
| `4 e 6` | 4 sets for the first weeks, 6 for the last weeks — the notes say when the switch happens |
| `2 e 3` | same, for reps |
| `\\` | not applicable / see the notes column |
| `rt` | *rep totali* — a total-rep target for the exercise, sets free |
| `80-` | start at 80 total reps, increasing weekly (notes: +10/week) |
| `5+5+5+5` | cluster set — four blocks of 5 reps with a short intra-set rest (notes: 20") |
| `1+1+1` | cluster set of singles with intra-set rest (notes: 30") |
| `2 x l` | 2 reps per side (*per lato*) |
| `6+12"` | a compound prescription — 6 reps then a 12-second hold, in the same set |
| `ladder` | ascending/descending ladder, rules in the notes |
| `max` | hold or rep out to technical failure, within the stated window |
| `iso` | isometric hold |
| `tuck ad.` | *tuck avanzato* — advanced tuck |
| `loop` | resistance band used as assistance; **progress by scaling the band down** |
| `+` (in prose) | *più* ("sempre + tempo" = more time) |

## Observations for the framework

Things this program does well and the framework should match:

1. **Warm-up is stated once**, for the whole block, and includes joint prep with
   a band plus movement-specific preparation — not a generic "5 min cardio".
2. **The notes column is the coaching.** Sets and reps are almost meaningless
   without it: the note carries the tempo, the intra-set rest, the week-by-week
   change, the technical focus and the stop signal.
3. **Hold-time windows with an exit criterion** — "min 5", max 10", above 10" we
   change the progression" is exactly the right shape for an isometric.
4. **Band assistance as the fine-grained load axis** for planche and lever
   holds, progressed by using a lighter band rather than jumping a leverage rung.
   This is a real gap the framework had.
5. **A named structure in the warning** — "fastidi al gomito zona capo lungo del
   bicipite ci fermiamo" (discomfort at the long head of the biceps and we stop).
6. **Video requested inline**, per exercise, where the coach cannot judge from a
   report.
7. **End-of-block caution flagged in the notes** — "occhio che sei a fine scheda,
   sopratutto articolazioni del gomito": accumulated fatigue changes the risk
   profile in the last weeks.

Things the framework adds on top:

- an explicit **volume budget** per movement pattern, and a push:pull check;
- **full exercise cards** — setup, phase-by-phase execution, cues, faults,
  regressions, references — rather than a name plus a note;
- written **regression** triggers alongside the progression ones;
- a **pain traffic light** and named substitutions per exercise;
- the constraint block (`PROBLEM` in the source) expanded into constraints with
  a substitution, an earn-it-back criterion and a re-test date;
- a scheduled **review** with the markers to be retested.
