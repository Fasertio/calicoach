# Grip, Forearm and Wrist Catalogue

Grip is the limiter for hanging volume, levers, one-arm work and the human flag.
The wrist is the limiter for handstands, planche and floor pressing. Both adapt
slowly and both are usually under-trained.

---

## Grip types and what trains them

| Grip type | Demand | Trained by |
|---|---|---|
| **Support (crush) grip** | holding bodyweight on a bar | dead hangs, farmer's carries, heavy rows |
| **Pinch grip** | thumb against fingers | plate pinches, thick-bar work |
| **Crush grip** | closing the hand | grippers, towel work |
| **Extension** | opening the hand — the antagonist | rubber-band finger extensions, rice bucket |
| **Wrist flexion / extension** | isometric wrist stability | wrist curls, wrist push-ups, false-grip work |
| **False grip** | wrist flexed over the bar/rings | false-grip hangs, ring rows in false grip |

Train **grip extension** as well as flexion. The imbalance between the two is a
common contributor to medial and lateral elbow pain in high-volume pullers.

## Dead Hang **[full]**

| | |
|---|---|
| **Pattern** | grip + shoulder tissue tolerance |
| **Type** | isometric |
| **Primary muscles** | forearm flexors (FDS, FDP), brachioradialis |
| **Secondary muscles** | latissimus dorsi, lower trapezius (in the active version), scapular stabilisers, thoracic and shoulder connective tissue |
| **Equipment** | pull-up bar or rings |
| **Difficulty** | beginner |
| **Skill prerequisite** | none |

**Why it is here:** it builds the grip and shoulder tissue tolerance that every
hanging exercise depends on, and it is the cheapest shoulder-health investment in
the catalogue.

### Setup
1. Grip the bar slightly wider than shoulder width, thumbs wrapped around.
2. Hang with arms straight, feet off the floor. Legs together and slightly
   forward, glutes lightly engaged.

### Execution
- **Passive hang:** shoulders allowed to rise toward the ears, but the trunk
  stays controlled — not floppy. Used for tissue tolerance and grip.
- **Active hang:** shoulders pulled down and away from the ears (scapular
  depression), arms still straight. Used for scapular strength and as the
  pull-up start position.
- Hold for time, breathing normally. Step down under control — do not drop.

### Cues
- "Full grip, thumbs around."
- Passive: "let the shoulders relax but keep the body still."
- Active: "shoulders away from the ears, arms locked."

### Breathing
Normal, continuous. Grip fails faster when the athlete holds their breath.

### Tempo
Isometric. Prescribe seconds.

### Common faults
| Fault | Why it matters | Fix |
|---|---|---|
| Dropping off the bar at the end | landing under fatigue is the fall risk | set a box under the feet; end the set with 3 s in reserve |
| Swinging | wastes grip, irritates the shoulder | start still, hold still |
| Thumbless grip on long holds | slip risk | thumbs around unless there is a specific reason |
| Shrugged and tense passive hang | not actually relaxing, so no tissue benefit | exhale, let the ribs settle |

### Risk notes
Introduce hanging volume gradually — a beginner going from zero to five minutes
of daily hanging will develop medial elbow or shoulder irritation. Start at
3 x 20 s and add ~10% per week. Athletes with shoulder instability should start
with feet lightly supported.

### Regressions (easier → this)
1. Feet-supported hang (toes on a box, taking 30–50% of bodyweight).
2. Band-assisted hang.
3. Bar hang with a wider stance on a low bar, feet on the floor.

### Progressions (this → harder)
1. Increase total time (3 x 20 s → 3 x 60 s).
2. Active hang with scapular depression.
3. One-arm hang with the free hand on the wrist, then on the forearm, then free.
4. Towel hang, thick-bar hang, or false-grip hang.
5. Weighted hang (vest or belt).

### Substitutes
Farmer's carries and heavy rows for grip when hanging is contraindicated.

### References
- Overcoming Gravity, Steven Low — hanging progressions and grip development.
- Clinical literature on progressive tendon loading — the same graded-exposure
  logic applies to grip and shoulder tissue.
- Video search terms: "dead hang active vs passive", "scapular depression hang".

## Compact catalogue — grip

| Exercise | Dose | Notes |
|---|---|---|
| **Farmer's carry** | 3–4 x 30–40 m | support grip plus lateral core; the best all-round grip builder |
| **Suitcase carry** | 3 x 20–30 m per side | grip + anti-lateral flexion |
| **Towel hang / towel row** | 3 x 20–30 s | brutal on the grip; excellent for climbers and flag work |
| **Thick-bar hang** | 3 x 15–25 s | use a towel wrap if no thick bar is available |
| **Plate pinch** | 3 x 20–30 s per hand | thumb strength; directly transfers to the human flag |
| **False-grip hang** | 3 x 10–20 s | mandatory preparation for the ring muscle-up; builds wrist tolerance slowly |
| **One-arm hang progression** | 3 x 10–20 s per side | free hand on the wrist → forearm → free; progress over months |
| **Captains-of-crush style gripper** | 3 x 5–8 | optional; crush grip only |
| **Wrist roller** | 2–3 x 1–2 rolls each way | flexors and extensors together |

## Compact catalogue — forearm and elbow health

| Exercise | Dose | Notes |
|---|---|---|
| **Wrist curl (flexion)** | 3 x 12–20 | medial elbow tolerance; slow eccentric |
| **Reverse wrist curl (extension)** | 3 x 12–20 | lateral elbow tolerance; almost always the under-trained side |
| **Pronation / supination with a hammer or club** | 3 x 10–15 each way | rotational forearm strength, protects the elbow in ring work |
| **Finger extension with a rubber band** | 3 x 15–25 | antagonist to all gripping; cheap and effective |
| **Rice bucket work** | 2–3 min | general forearm circulation and endurance; useful in a rehab context |
| **Tyler-twist style eccentric (flexbar)** | 3 x 15 | commonly used for lateral elbow tendinopathy; slow eccentric emphasis |
| **Elbow flexor isometric (biceps hold at 90°)** | 5 x 30–45 s | first-line loading for irritable distal biceps and for straight-arm tolerance |

## Compact catalogue — wrist mobility and load tolerance

Run this as a **wrist prep protocol** before any handstand, planche or floor
pressing session. 3–5 minutes.

| Drill | Dose | Notes |
|---|---|---|
| Wrist circles, both directions | 10 each way | gentle warm-up |
| Palm-down rocks (fingers forward) | 10 slow rocks | build extension under load |
| Palm-down rocks (fingers backward) | 10 slow rocks | flexor stretch; go gently, this one is often sharp |
| Fingertip pulls (fingers backward, lift the palm) | 10 reps | trains active extension range |
| Side-to-side wrist rocks | 10 each way | radial/ulnar tolerance |
| Fist-to-palm transitions | 10 reps | prepares for both fist and flat-hand loading |
| Wrist push-ups (on the backs of the hands, unloaded) | 10 reps | approach carefully; skip with any TFCC symptoms |

**Progression rule for the wrist:** it adapts to *frequency*, not intensity. Daily
2–3 minute exposures beat one long weekly session. Increase weight-bearing time
by ~10% per week.

## Grip and elbow programming policy

- Grip work goes **last** in a session, unless grip is the day's primary target.
- Never let grip failure be the reason a pull or lever set ends when the point of
  the set is the back or the shoulder. Use straps in that case, and train grip
  separately.
- Rotate grips across the week (pronated / neutral / supinated / rings).
- If medial or lateral elbow pain appears: cut pulling volume ~40%, remove all
  straight-arm work, and start the isometric → heavy-slow-resistance protocol in
  [injury-prevention](../../injury-prevention/SKILL.md).
- False grip is a slow adaptation. Introduce it 8–12 weeks before muscle-up work
  is expected, at 3 x 10 s, and build from there.
