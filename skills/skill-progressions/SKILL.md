# Skill Progressions

Skills are not exercises you attempt; they are ladders you climb. The coaching
job is picking the correct rung, capping the volume, and refusing to advance
early.

**Announce it:** "Using skill-progressions to plan your \<skill\> work."

## Before any skill work — the gate

Check all of these. A failure on any line means the athlete is not ready, and the
answer is a foundation block, not a modified skill attempt.

| Gate | Requirement |
|---|---|
| Screening | no active shoulder, elbow or wrist constraint relevant to the skill |
| Straight-arm tolerance | B2 straight-arm probe passed, and no symptoms in the 24 h after |
| Bent-arm base | 8+ strict pull-ups and 12+ dips for pulling skills; 20+ push-ups for pressing skills |
| Trunk | 45 s hollow hold with a flat low back |
| Scapular control | 5 clean scapular pull-ups with a 2 s hold |
| Training history | 8+ weeks of consistent, uninterrupted training |
| Wrist (for planche/handstand) | 60 s pain-free flat-hand front support, or parallettes available |

Athletes hate this gate. Explain it once — connective tissue adapts in months,
and the gate is what stops a six-week enthusiasm from becoming a six-month
injury — then hold it.

## Universal rules for skill training

1. **One primary skill per block.** A second skill is maintenance at ~50% of its
   volume. Three is a plan to progress at nothing.
2. **Skill work is first in the session, always.** Fresh, after a full warm-up,
   before any fatiguing strength work.
3. **Frequency over duration.** 3–5 short exposures per week beats one long
   session, particularly for the handstand.
4. **Never train to position failure.** Stop the set when the position is about
   to break (RPE ~8), not when it breaks.
5. **Quality clock.** Hold time counts only while the position is correct. A
   12 s hold with 4 collapsed seconds is an 8 s hold — and you record 8.
6. **Volume caps.** Straight-arm skill TUT: 60–120 s/week in the first four
   weeks, 120–240 s/week in development, never climbing more than 10% per week.
7. **Leverage advances are planned, not improvised.** One step per 2–3 weeks
   maximum, and volume drops 30% in the week of an advance.
8. **Elbow symptoms end the skill session.** Not "finish the set" — end it, and
   run the elbow protocol from
   [injury-prevention](../injury-prevention/SKILL.md).
9. **Film it.** Skills fail invisibly. One side-on clip per week per skill.
10. **The bent-arm base keeps progressing.** A skill block that abandons pull-ups
    and dips produces a temporary skill and a weaker athlete.

## Setting hold-time targets

| Stage | Prescription | Advance when |
|---|---|---|
| Introduction | 5 x 5–8 s, RPE 7, long rests | clean quality at every set, no next-day symptoms, 2 sessions |
| Development | 5 x 10–12 s, RPE 8 | target time at every set, 2 consecutive sessions |
| Consolidation | 4 x 15–20 s, or 3 x 20 s+ | comfortable, then advance leverage |

When advancing a leverage step, restart at the introduction stage of the new
rung. Do not carry the old rung's hold times forward.

## Programming a skill alongside strength

| Skill block content | Effect on the rest of the program |
|---|---|
| Planche work | reduce horizontal pressing volume ~30%; keep pulling volume high |
| Front lever work | reduce vertical pulling volume ~20%; keep pressing normal |
| Back lever work | reduce all straight-arm pulling; the highest biceps-tendon cost of any common skill |
| Handstand work | minimal interference; the shoulder-flexion volume adds up, so watch overhead pressing |
| Muscle-up work | keep pull volume high; add explosive pull and transition work; reduce dip volume slightly |
| Human flag work | high oblique and lateral core cost; reduce other lateral core work |
| One-arm pull-up work | very high elbow cost; treat like straight-arm work for volume caps |

## Progression assessment

Every 2 weeks, per skill, record:

- best clean hold at the current leverage (quality clock),
- total weekly TUT actually completed,
- any joint symptoms during or in the 24 h after,
- one side-on video.

Then decide: **advance / hold / regress**. Write the decision and its reason into
the program changelog.

## Definition of done

- [ ] The gate was checked, line by line
- [ ] The correct rung was chosen — the hardest one held with clean quality
- [ ] Weekly TUT cap set and written into the program
- [ ] Advance and regress criteria written with numbers
- [ ] Skill scheduled first in the session, with adequate rest
- [ ] Complementary accessories programmed (straight-arm pulldown, hollow work,
      wrist and elbow prep)
- [ ] Interference with the rest of the program accounted for
- [ ] Full exercise cards produced for every skill drill prescribed
