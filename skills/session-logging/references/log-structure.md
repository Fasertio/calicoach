# Session Log Structure

`calicoach/logs/YYYY-MM-DD_wWdD.md` — one file per session. Keep it fast to fill
in; an athlete will not maintain a form that takes longer than the cool-down.

## Minimum viable log

If the athlete will not maintain the full table, accept this — it is still enough
to coach from:

```markdown
# 2026-09-08 w1d1
Sleep 7 h. Energy 7.
Front lever 5x10s (last two shaky). Weighted pull-up 4x5 +10kg, last set 4.
Rows and accessories as written.
Slight inner-elbow niggle 1/10 on straight-arm pulldown, gone after.
Felt good.
```

Ask for exactly this and no more from athletes who resist logging. Then read it
carefully — that niggle line is the whole point of the exercise.
