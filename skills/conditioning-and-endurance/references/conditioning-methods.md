# Conditioning Methods

Bodyweight-first protocols, each with the marker it moves, the dose to start
at, and what it costs the rest of the block. Machines are optional throughout;
where one is genuinely better, it says so.

Every one of these is subject to the active constraints. A circuit is not a
loophole: if the screen removed overhead pressing, there are no overhead
presses in the circuit either.

---

## 1. Short maximal efforts — the cheapest conditioning there is

**Trains:** phosphagen, and the aerobic system that refills it.
**Costs:** almost nothing. This can sit at the end of a strength day.

| | |
|---|---|
| Structure | 6–10 × 10–15 s all-out, 60–90 s easy between |
| Modality | assault bike, rower, hill sprint, sled push, skipping |
| Start at | 6 efforts, and add one a week |
| Marker | peak output held across the set; the last effort within 10% of the first |

**Why it is first on this list:** it raises work capacity with no meaningful
strength cost, because the efforts are too short to accumulate the fatigue that
interferes. For a strength or skill athlete who wants an engine, this is
usually the entire answer.

---

## 2. Easy steady state — the base nobody wants to do

**Trains:** oxidative, and therefore between-set recovery.
**Costs:** little, if it is genuinely easy. Most of its bad reputation comes
from athletes doing it too hard.

| | |
|---|---|
| Structure | 20–45 min continuous, conversational |
| Modality | walk on an incline, easy row, easy bike, easy ruck |
| Intensity | able to hold a full sentence. If not, slow down |
| Start at | 2 × 20 min a week |
| Marker | heart rate at a fixed pace, or pace at a fixed heart rate |

**The discipline is the pace.** Steady work done at a moderate-hard intensity
is the single most expensive conditioning an athlete can do: it costs like
intervals and trains like nothing.

## 3. Circuits — moderate, and more expensive than they look

**Trains:** mixed.
**Costs:** moderate systemically, and a great deal of joint volume that no
pattern row counts.

| | |
|---|---|
| Structure | 4–6 exercises, 30–40 s work, 20–30 s transition, 3–5 rounds |
| Selection | alternate patterns so nothing is worked twice in a row |
| Start at | 3 rounds, one circuit a week |
| Marker | rounds completed with technique intact, or total reps in a fixed time |

**Count the sets.** A 5-exercise circuit for 4 rounds is 20 sets. Put them in
the pattern budget as well as the conditioning minutes, or the week's volume is
quietly double what the budget says.

**Never in a circuit:** straight-arm holds, skill work, anything with a fall
risk, anything a constraint restricts, anything the athlete has not performed
cleanly when fresh.

---

## 4. EMOM — the structure that enforces its own pacing

**Trains:** mixed, and controllable.
**Costs:** moderate; scales cleanly, which is its main virtue.

| | |
|---|---|
| Structure | every minute on the minute, a fixed piece of work, rest is what remains |
| Dose | the work should take 30–40 s, leaving 20–30 s of rest |
| Duration | 10–20 min |
| Marker | the same work in the same minutes with more rest left over |

**Why it is the best circuit for a strength athlete:** the clock, not the
athlete, sets the pace, and the rest is visible. When the work starts eating
the rest, the piece is over — which is a stop signal rather than a judgement
call under fatigue.

---

## 5. Density work — fixed time, count the work

**Trains:** mixed, biased aerobic if the sets stay short of failure.
**Costs:** moderate, and self-limiting.

| | |
|---|---|
| Structure | one or two exercises, fixed window (10–20 min), as many quality sets as possible |
| Rule | every set stops 2–3 reps short of failure, the whole way through |
| Start at | 10 min, one exercise |
| Marker | total quality reps in the window |

**This is the friendliest structure for a bodyweight athlete** because it uses
the movements the athlete is already good at, and the "short of failure" rule
keeps the technique intact.

---

## 6. Loaded carries — conditioning that builds something

**Trains:** mixed, plus trunk and grip.
**Costs:** grip and trunk, which a skill block is already spending.

| | |
|---|---|
| Structure | 4–6 × 30–60 m, rest twice the work time |
| Variants | farmer, suitcase (anti-lateral-flexion), front rack, overhead if cleared |
| Start at | half bodyweight total, farmer only |
| Marker | distance at a load, or load at a distance |

**Watch the overlap.** If the block contains front lever, one-arm work, or
heavy pulling, carries compete for the same grip and elbow budget. Either
reduce them or use suitcase carries, which cost the trunk more and the grip
less.

---

## Choosing between them

| The athlete wants | Give them |
|---|---|
| An engine without losing strength | 1 and 2 |
| To feel fitter, fast | 4 |
| A marker that moves in six weeks | 5, on a movement they already own |
| General work capacity for sport | 1, 3 and 5 |
| To lose fat | 2, plus [recovery-and-nutrition](../../recovery-and-nutrition/SKILL.md) — conditioning is a poor fat-loss lever compared with food |
