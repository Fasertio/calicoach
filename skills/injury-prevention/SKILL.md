# Injury Prevention and Load Management

The job is to make the program survivable. Every session has joint prep; every
program has load guardrails; every symptom has a written response.

**Announce it:** "Using injury-prevention to \<purpose\>."

**This is training guidance, not treatment.** Red flags stop programming and go
to a clinician — see
[safety-and-scope](../calisthenics-coach/references/safety-and-scope.md).

## The three layers

1. **Prep** — what happens before loading, every session.
   → [warm-up-protocols.md](references/warm-up-protocols.md)
2. **Prehab** — targeted strengthening built into the program, every week.
   → [prehab-protocols.md](references/prehab-protocols.md)
3. **Load management** — the rules that stop the program from outrunning the
   tissue.
   → [tendon-loading.md](references/tendon-loading.md)

## The pain traffic light — write this into every program

| Light | Signal | Action |
|---|---|---|
| **Green** | 0–2/10, warms up and disappears, gone next morning | continue as programmed |
| **Amber** | 3–4/10, present during the set but no worse after, settles within 24 h | reduce range or load, take the written regression, keep it under 4/10, retest next session |
| **Red** | >4/10, sharp, worsening within the session, still present after 24–48 h, or changing how the joint moves | stop that movement, substitute the named alternative, tell the coach |

**Two consecutive amber sessions on the same structure is treated as red.**

## Load guardrails

These override every progression rule in the program.

| Guardrail | Number |
|---|---|
| Weekly increase in total hard sets | ≤ 10% |
| Weekly increase in straight-arm isometric TUT | ≤ 10% |
| Leverage advances per skill | ≤ 1 per 2–3 weeks |
| Volume in the week of a leverage advance | −30% |
| Restart after a 2–4 week layoff | 60% of previous volume, rebuild over 2–3 weeks |
| Restart after 1–3 months off | 50% volume, regress leverage one full step |
| New skill introduction | one at a time, 4+ weeks apart |
| Deload frequency | every 4–6 weeks, or on signal |
| Straight-arm work after any elbow symptom | zero for at least 1 week, then restart at 60% |

## The high-risk list for calisthenics

Know where the injuries actually come from. Program defensively around these.

| Structure | Mechanism | The defensive move |
|---|---|---|
| **Distal biceps tendon / brachialis (elbow)** | straight-arm work: planche, front and back lever, one-arm work | volume caps, elbow prep every session, zero tolerance for symptoms |
| **Common flexor origin (medial elbow)** | high-volume pronated pulling, false grip, heavy grip work | grip rotation across the week, wrist flexor and extensor work |
| **Long head of biceps (anterior shoulder)** | dips, deep pressing, planche lean, end-range extension | dip depth limits, cuff and scapular work |
| **Rotator cuff / subacromial structures** | overhead volume with poor scapular upward rotation | screen overhead range first; face pulls and cuff work every week |
| **Wrist (extension load)** | handstands, planche, floor pressing | daily wrist protocol, parallettes, +10%/week rule |
| **Lumbar spine** | sagging in levers and planche, loaded flexion, hinge under fatigue | anti-extension core priority, hinge technique standards |
| **Patellar tendon / patellofemoral** | jumping volume, deep loaded knee flexion, pistols too early | isometric quad work, pain-free range only, gradual jump exposure |
| **Achilles** | sudden jump or calf volume increases | progressive calf loading, no volume spikes |
| **Shoulder capsule (instability)** | end-range positions under load, muscle-up transitions, skin-the-cat | strict gates, mid-range strength first |

## When the athlete reports pain

1. **Characterise it** — standard six questions from
   [interaction-protocol](../calisthenics-coach/references/interaction-protocol.md).
2. **Screen for red flags.** Any hit → stop that region, refer, keep coaching the
   rest.
3. **Classify the light** — green / amber / red.
4. **Apply the response**: reduce, substitute, or remove. Name the exact
   substitute exercise; never leave a hole in the program.
5. **Start a loading protocol** if it looks like a tolerance problem
   ([tendon-loading.md](references/tendon-loading.md)).
6. **Write it down** — into `screening.md` as a constraint with a re-test date,
   and into the program's changelog.
7. **Set a review point.** If it is not improving in 2–4 weeks, refer.

## Prep is not optional

Every session gets 8–12 minutes:

- 3–5 min pulse raiser (bike, rope, brisk walk, easy movement)
- joint prep for the joints the session will load (see
  [warm-up-protocols.md](references/warm-up-protocols.md))
- specific ramp-up sets of the first exercise, 2–3 progressively harder sets

Static stretching goes **after** training, not before. Dynamic and active
mobility go before.

## Prehab is part of the program

Every session ends with 8–12 minutes of targeted work, chosen from
[prehab-protocols.md](references/prehab-protocols.md) based on what the session
loaded and what the screen found. Cutting prehab to save time is the same as
cutting the program's insurance policy.

Minimum weekly prehab for a calisthenics athlete:

| Region | Dose |
|---|---|
| Rotator cuff (external rotation) | 3 x 12–15, 2–3x per week |
| Scapular (face pull, band pull-apart, prone Y/T) | 3 x 12–20, 3x per week |
| Elbow (wrist flexor + extensor + pronation/supination) | 3 x 12–20, 2–3x per week |
| Wrist protocol | every session that loads the hands |
| Glute medius / hip | 3 x 12–20, 2x per week |
| Calf / ankle | 3 x 12–20, 2x per week |
| Neck and grip extension | 2 x 15, 2x per week |

## Definition of done

- [ ] Warm-up prescribed for the specific joints the session loads
- [ ] Prehab block present in every session, matched to the screen findings
- [ ] Traffic-light rules written into the program
- [ ] Load guardrails respected in the progression plan
- [ ] Any reported symptom characterised, classified, substituted and recorded
- [ ] Re-test date set for every symptom-driven constraint
- [ ] Referral advised where the red-flag criteria are met
