# Prehab Protocols

Targeted strengthening built into the program, 8–12 minutes at the end of each
session. Choose by what the session loaded and what the screen found.

These are **training** protocols for asymptomatic or mildly irritable tissue. A
painful, worsening or red-flag structure goes to a clinician.

---

## Shoulder

**Program 2–3x per week for anyone doing pulling, pressing or overhead work.**

| Exercise | Dose | Purpose |
|---|---|---|
| Face pull with external rotation | 3 x 15–20 | posterior cuff, scapular retraction — the single highest-value prehab exercise for this sport |
| Band external rotation at 0° abduction | 3 x 12–15 | infraspinatus/teres minor |
| Band external rotation at 90° abduction | 3 x 12 | cuff at the working angle for overhead skills |
| Prone Y raise | 3 x 12 | lower trapezius |
| Prone T raise | 3 x 12 | middle trapezius |
| Serratus wall slide / scapular push-up | 3 x 10–12 | upward rotation, protraction |
| Bottoms-up kettlebell carry or press | 3 x 20 s / 3 x 8 | cuff co-contraction under a stability demand |
| Ring support hold | 3 x 20–30 s | straight-arm stability |

**Progression:** these respond to load, not just reps. Move from band to cable to
dumbbell over a block; keep the rep range 12–20 and the tempo slow.

## Elbow

**Mandatory alongside any straight-arm skill work, one-arm work, or high-volume
pulling.**

| Exercise | Dose | Purpose |
|---|---|---|
| Wrist curl (flexion) | 3 x 15–20, 3 s eccentric | medial elbow / common flexor origin |
| Reverse wrist curl (extension) | 3 x 15–20, 3 s eccentric | lateral elbow / common extensor origin — the usually neglected side |
| Pronation/supination with a hammer or club | 3 x 12 each way | rotational tolerance |
| Elbow flexor isometric at 90° | 5 x 30–45 s | distal biceps tendon tolerance |
| Slow eccentric curls | 3 x 8, 4 s down | biceps tendon loading |
| Straight-arm plank / lean progression | 3 x 20–30 s | position-specific tolerance |
| Finger extension with a rubber band | 3 x 20 | grip antagonist |

## Wrist

Every session that loads the hands. See the protocol in
[warm-up-protocols.md](warm-up-protocols.md); add these as strengthening:

| Exercise | Dose |
|---|---|
| Wrist push-ups (on the backs of the hands, controlled) | 2 x 10 |
| Fingertip push-ups against a wall | 3 x 10 |
| Weight-bearing wrist rocks under progressive load | 3 x 30 s |
| Wrist roller | 2 x 1–2 rolls each way |

## Lumbar spine and trunk

| Exercise | Dose | Purpose |
|---|---|---|
| Dead bug | 3 x 8 each side | anti-extension with the lowest risk |
| Bird dog | 3 x 8 each side | coordination and mild extension |
| Pallof press | 3 x 12 each side | anti-rotation |
| Side plank | 3 x 30–45 s each | lateral chain, quadratus lumborum |
| Glute bridge / hip thrust | 3 x 12–15 | hip extension without spinal load |
| Back extension to neutral | 3 x 12 | erectors, stopping at neutral |
| Suitcase carry | 3 x 20–30 m each side | integrated anti-lateral-flexion |

McGill's "big three" (curl-up, side plank, bird dog) is a reasonable default
starting point for an athlete with a history of non-specific low back pain — as
training, alongside clinical care, not instead of it.

## Hip and knee

| Exercise | Dose | Purpose |
|---|---|---|
| Copenhagen plank progression | 3 x 15–30 s each side | adductor strength — the best-supported groin injury prevention there is |
| Side-lying hip abduction | 3 x 15 each | glute medius |
| Banded lateral walk | 3 x 10 steps each way | glute medius under load |
| Clamshell | 3 x 15 each | hip external rotators |
| Nordic hamstring curl (or a regression) | 2–3 x 3–6 | hamstring eccentric strength; start very low, it is extremely demanding |
| Spanish squat / wall sit | 5 x 30–45 s | isometric quad, patellar tendon tolerance |
| Step-down, slow eccentric | 3 x 8 each | knee control under load |
| Hip airplane | 3 x 6 each | rotational hip control |
| Terminal knee extension with a band | 3 x 15 | vastus medialis emphasis |

## Ankle, calf and foot

| Exercise | Dose |
|---|---|

| Single-leg calf raise | 3 x 12 each |

| Single-leg balance, eyes open then closed | 3 x 30 s each |
| Toe splay / short foot drills | 2 x 30 s |

|---|---|

| Chin tucks | 2 x 12 |

## Choosing what to program

| Session type | Prehab block |
|---|---|
| Pull day | face pull, prone Y, elbow protocol, grip extension |
| Push day | cuff external rotation, serratus, wrist protocol |
| Skill day (straight-arm) | full elbow protocol + wrist protocol + cuff |
| Leg day | Copenhagen, glute medius, calf, Nordic regression |
| Hinge day | dead bug, side plank, back extension, hamstring |
| Handstand day | wrist protocol, neck, cuff, serratus |

Plus: anything the screen flagged as `Limited` goes in every session until it
re-tests as `Pass`.

---

## Making prehab actually happen

- Put it **in the program table**, with sets and reps, like any other exercise.
  Prehab written as "do some band work" does not get done.
- Attach it to the end of a session as a fixed circuit — 2 rounds of 4 exercises,
  no rest between exercises, 60 s between rounds.
- Keep it under 12 minutes.
- Progress it. Prehab at the same load for six months is a warm-up, not
  training.
